# Ebook Studio IA

MVP de um estúdio para criação de e-books low ticket com fluxo em 6 etapas:

1. Conteúdo
2. Estilo
3. Imagens
4. Diagramação
5. Revisão
6. Exportação

## Stack

- React + Vite
- Supabase
- GitHub

## Status atual

A interface inicial já está criada e conectada ao projeto Supabase `Ebook Studio IA`.

Próximas etapas:
- persistir projetos no Supabase;
- upload real de PDF/DOCX para Storage;
- geração de capa, contracapa, ilustrações e mockup;
- motor de diagramação;
- exportação de PDF digital e para impressão.
